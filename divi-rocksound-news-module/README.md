# Module Divi "Rocksound - Actualités"

Ce plugin ajoute :

- un module Divi **Rocksound - Actualités**
- un shortcode `[rocksound_news]`

## Installation

1. Compresser le dossier `divi-rocksound-news-module` en `.zip`.
2. Dans WordPress, aller dans **Extensions > Ajouter > Téléverser une extension**.
3. Activer l'extension.
4. Dans le Divi Builder, ajouter le module **Rocksound - Actualités**.

## Options du module

- **Nombre d'actualités** : 1 à 12
- **Lignes d'extrait** : 2 à 5
- **Afficher la date** : oui/non
- **Slug catégorie** (optionnel)

## Exemple shortcode

```text
[rocksound_news posts="6" lines="4" show_date="on" category="actu-rock"]
```
